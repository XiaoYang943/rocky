# 发行内容与来源边界

当前 SDK 0.3.0／ABI 62 不变。本轮只改变代码归属和安装内容，不修改引擎渲染算法。

| 目录 | 当前用途 | 处理 |
| --- | --- | --- |
| resources | Terrain、Entity、Atmosphere 和 3D Tiles 的 Shader／纹理；字体数据 | 保留，随 SDK 安装；不能整体删除 |
| provenance | 固定来源、原文件与现文件映射、完整 patch、许可证及历史研究证据 | 源码仓库保留；安装和 Demo 打包只选当前来源文件 |
| tools | 上游 vsgconv 转换程序，不属于 Reader SDK 实现 | 不构建、不安装，已按明确授权删除 |
| examples | 剩余上游示例和大样例模型，不参与当前构建 | 活动代码已迁走；剩余目录已按明确授权删除 |

## 活动代码归属

历史 ImGui adapter 来源保留在 Demo `native/ui`；当前 Tauri Demo 不再编译或链接它。SDK 的 src、header 清单、CMake 配置和安装产物均不需要 ImGui。需要 GUI 的其他宿主自行适配；React 与原生视口的边界见 Demo 当前文档。

安装消费测试位于 SDK `tests/package-consumer`。verify-package.ps1 使用 `.build/package-consumer-layout`，不会复用绑定旧源码目录的 CMake Cache。Core/Data 与完整 SDK 两个 console consumer 均应运行，不能只验证编译。

## 安装与打包

cmake/InstallProvenance.cmake 从当前 manifest 读取各来源的 module-files 和活动 patch，共 7 个来源文件。许可证独立安装到 share/GeoStudioNative/licenses。完整来源历史仍在 Git 与源码目录。

Demo stage-native.ps1 只复制这 7 个文件和 build-manifest、dependencies.lock；不再重复复制 resources／旧 patch／研究资料。runtime 资源和第三方许可证仍按原运行目录单独装配，UI 自身 provenance 单独携带。

增量安装不会删除旧文件。新目录可用 `cmake --install` 的 `--prefix` 核验；完整 consumer 接受 `scripts/verify-package.ps1 -InstallDirectory <新安装目录>`。严格来源闭包检查命令为 `python -B tests/architecture/check_package_contents.py --installed <新安装目录>`。

Demo 可以使用 `scripts/stage-native.ps1 -Destination <新的 staging 目录>` 验证文件装配。指定目录不改变 Tauri 的固定资源路径，也不会自动发布。默认目录如果仍有 source-patches 或多余 SDK metadata，会明确停止并指出需手动清理的位置，不把旧历史文件混入新发行包。

## 来源恢复

SDK examples／tools 的 110 个明确文件已移除，其原路径、大小与 SHA-256 保存在 [removed-upstream-files.json](../../provenance/removed-upstream-files.json)。固定来源版本、module-files、完整 patch 与二进制删除身份继续保存在 provenance；原件从登记的固定 ZIP 恢复，不把历史清单当作原件。

resources、provenance、tests 与 Demo 来源副本不在这项上游文件删除范围内。旧 staging 和其他制品也不随文档整理删除。来源核验仍是安装与打包的前置条件。
