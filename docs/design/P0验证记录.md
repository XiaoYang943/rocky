## 失败、修复和边界

- 首次 build-r1 发现 vsgXchange 自动选择 Native 依赖中的 KTX package，缺少 ktxvulkan.h。SDK 关闭此前未启用的 vsgXchange KTX Reader；Cesium Native 的 KTX2 解码保留，两份实数据回归通过。
- 初始 DLL 组合的 IPC 退出返回 0xc0000005，smoke 已输出 closed 但进程退出仍异常；不能仅看 closed 事件判成功。将 Runtime 持有的 GPU／Viewer 引用在主动 shutdown 阶段释放后，IPC、smoke、真实 Tileset 退出均恢复 0。原失败日志保留。
- Rocky 保持 static linkage，避免与宿主各自静态链接 ImGui 而产生两个 context；static CMake package 补齐 GDAL／CURL／imgui dependency lookup。
- 不新增临时性能指标，不覆盖所有 3D Tiles 1.1 扩展，不代表 MBTiles、OSGB 原件、LAS／LAZ、编辑或性能专项完成。新机器 bootstrap、跨平台与 Debug 未实测。
