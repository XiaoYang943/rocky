## 实际修改与行为

源码按 core／data／scene／drivers／streaming／render／runtime 归类。Import 放入 render/import，GIS 数据访问放在 drivers；各 cesium 子目录按实际职责归属，由私有 C++20 target 编译。Map、Layer、Tileset JSON 和原输入协议不变。源代码 namespace 保持 geostudio::native 与既有 io／tiles3d 子空间，未强制改外部依赖。

公开 include 迁移到 geostudio/native/<能力>/<子目录>。SDK 0.3.0、ABI 62，安装 out/install-capabilities。旧 Globe／IO／Tiles3D CMake alias 只作为消费迁移桥，源码没有对应顶层组件。旧 include 路径不继续导出。

原 Application 中的 Terrain Picking 移入 render/view，避免循环依赖。Application、View、VSGContext、ECSNode 的 ImGui 状态和装配移到宿主；Label 状态保留，LabelSystem／WidgetSystem 绘制由 examples/imgui-adapter 提供，包含按需渲染休眠期间的 UI 回调。vsgCs 未使用的可选 ImGui 纹理包装移除，通用 readRemoteImage 保留。

自有宏改为 GEOSTUDIO_NATIVE_*，static API 与 RuntimeTiles DLL Export 分开命名。版本比较宏修正括号并增加编译断言。Shader 的原文件名和 resources 位置不改。Slughorn 默认不启用；可选 smoke 的源码路径同步，但未安装该依赖或执行该测试。
