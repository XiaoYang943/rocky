# 安装、构建与使用

本文件对应 GeoStudioNative 0.2.0／NativeSDK-002。当前支持本机 Windows x64 Release、MSVC 动态 CRT。Linux／macOS、Debug 和新机器全量安装不冒充已验证。当前检查见[主任务](任务/002-Namespace与模块重组.md)。

## 环境

- Visual Studio Installer：安装“使用 C++ 的桌面开发”，MSVC v143、Windows SDK。脚本经 vswhere 自动导入 x64 环境。
- PowerShell 7、Git、CMake 3.22 或更高、Ninja 加入 PATH；本机沿用 CMake 4.3.2、MSVC 14.44.35207。
- Vulkan GPU 驱动。Headers／Loader／glslang 由固定依赖准备，不要求安装完整 Vulkan SDK。
- [工作区 GDAL SDK](../../../../third-party/gdal/README.md)：固定 GDAL 3.12.2、PROJ 9.6.2，路径 `third-party/gdal/sdk/gdal-3.12.2-windows-x64-msvc-sdk`。需要头文件、lib、bin、share 和 runtime-manifest.json；不从随机 GDAL 发行版混用 DLL。可用 `NG_GDAL_SDK` 指定相同版本的另一位置。
- 仅构建 SDK 不需要 Node、Rust 或 Qt。构建 React 桌面 Demo 另需 Node／pnpm、Rust MSVC 工具链与 WebView2，见[Demo 使用指南](../../../../demo/native-gis-demo/docs/使用指南.md)。

## 首次完整准备

以下命令在 SDK 根执行；默认 Cache 为 SDK `.deps`，有网络时下载锁定来源。SDK 已含 Rocky、vsgCs、vsgXchange 源码，不会重新从旧 Demo Cache 选择它们。

```powershell
Set-Location D:/code/xiaoyang943/Programming-Lab/GeoStudio/sdk/GeoStudio-Native
./scripts/bootstrap.ps1 -Jobs 6
./scripts/bootstrap-cesium.ps1 -Jobs 6
./scripts/verify-sources.ps1
./scripts/build.ps1 -Jobs 6
./scripts/verify-package.ps1
```

`bootstrap.ps1` 校验归档 SHA-256，准备 Vulkan、GLM、EnTT、spdlog、ImGui、Assimp、VSG 和 GDAL MVT 的固定源码，基础库安装到 `.deps/install`；`bootstrap-cesium.ps1` 准备固定 Cesium Native 和 vcpkg、Release dependency triplet。库采用 static linkage／dynamic CRT；不启用 EZVCPKG、自动清理和上游测试下载。

bootstrap 可加 `-Offline`，但要求全部源码包、工具和依赖下载已缓存。基础库续建可用 SDK 的 `-Only imgui`／`-From vsg`；Demo 兼容入口只转发 Jobs／Offline。内存不足降低 Jobs。失败保留日志和 Cache，不批量删除。

## 复用本机现有依赖

P0 本机验证明确复用 Demo 原 `.deps` 中的外部依赖，没有搬移大型 Cache，也没有重新消费其中旧 Rocky／vsgCs／vsgXchange：

```powershell
$env:GEOSTUDIO_NATIVE_DEPS = (Resolve-Path ../../demo/native-gis-demo/.deps).Path
./scripts/build.ps1 -Jobs 6
./scripts/verify-package.ps1
```

只在当前 PowerShell 设置环境变量。安装后的 build-manifest.json 保存本次 Cache 位置；后续 SDK／Demo 脚本可读取该位置。更换机器后显式指定新 Cache 或重新 bootstrap；不要继续引用不存在的旧路径。

## 可选完整 Globe 测试

执行 `./scripts/build.ps1 -Jobs 6 -WithTests` 会先构建并运行保留的 Globe 测试；任何失败都会停止安装，不会跳过失败继续报告成功。完整测试依赖额外的 PROJ `us_nga_egm96_15.tif` grid，以及可访问的外部 HTTPS 样本服务。本机缺少该 grid，因此完整套件为 96／97 cases 通过，Vertical Datum case 失败；HTTPS 样本曾失败、重跑通过，仍依赖外部网络。本轮构建、安装与消费方验证独立执行，详见[验证记录](Namespace与模块重组验证记录.md)。不要删除断言或将缺失环境冒充已通过。

## 输出与 CMake 消费

- `.build/modules-r1`：SDK 编译中间文件，保留失败与增量状态。
- `out/install-modules/include`：geostudio/native 下三个模块的公共 headers。
- `out/install-modules/lib`：Globe static library、Tiles3D／IO import libraries、匹配 external fmt 的 spdlog，以及 CMake package。
- `out/install-modules/bin`：geostudio-tiles3d、geostudio-io DLL。
- `out/install-modules/share/GeoStudioNative/resources/globe`、`share/GeoStudioNative/resources/tiles3d`：Shader／font／image resources。
- `share/GeoStudioNative`：来源清单、完整 patches、licenses、build-manifest.json。

```cmake
find_package(GeoStudioNative 0.2 CONFIG REQUIRED)
target_link_libraries(my_app PRIVATE GeoStudio::Native)
```

配置时 CMAKE_PREFIX_PATH 需包含 SDK 安装路径、基础依赖 install 和 Cesium dependency prefix；GDAL／PROJ／CURL 导入适配由安装包自动提供。共享 GDAL 位置通过 `NG_GDAL_SDK` 传入。完整可执行参数在 `scripts/verify-package.ps1`，其 consumer 只包含已安装 headers 和 targets。包不是包含所有依赖的独立发行 SDK；外部依赖路径必须可用，运行时 DLL／GDAL data 闭包由 Demo 打包脚本收集。

接口为同工具链 C++ ABI；不能将不同 MSVC CRT、GLM、spdlog、fmt 或 Debug／Release 混用。Tiles3D 私有的 GLM_FORCE_XYZW_ONLY 不传播给 consumer。Rocky 保持 static linkage，确保宿主和 Rocky 共用一份 ImGui context。

## 编译并打开 Demo

```powershell
Set-Location ../../demo/native-gis-demo
./scripts/build.ps1 -Jobs 6
./scripts/smoke.ps1
./scripts/stage-native.ps1
pnpm install --frozen-lockfile
pnpm test
pnpm test:tilesets
./scripts/build-desktop.ps1 -SkipInstall
```

新包为 `out/desktop-native-modules/native-gis-demo.exe`，旁边完整 `native/` 必须保留。旧 `out/desktop` 保留，不是本轮 SDK 包。双击新 EXE，点击“启动三维引擎”→“打开数据”→选择类型→系统资源管理器选择数据→加载。指定验收输入：

- `D:/data/3d/osgb/DNHDL/3DTILES/3dtiles10/tileset.json`。
- `D:/data/3d/osgb/DNHDL/3DTILES/geostudio-v13/tileset.json`。

直接调试可执行 Demo `./scripts/run-native.ps1 -Case imagery`；样本、中文路径与系统选择器步骤见 Demo 指南。SDK 改动先 build SDK，再 build／stage Demo；React／Rust 改动用 build-desktop。覆盖某个运行包前关闭该包，避免 Windows 文件占用；可以用 `-OutputDirectory` 指定另一个明确新目录。

## 常见问题

- `GeoStudioNativeConfig.cmake` 缺失：先构建并安装 SDK，不要绕回旧 `.deps/patched` 源码。
- `Imported source changed`：先检查修改是否属于已授权变更，再维护完整 patch／manifest；不要直接改哈希掩盖差异。
- `ktxvulkan.h` 缺失：SDK 关闭未验证的 vsgXchange KTX Reader；3D Tiles 的 KTX2 继续由 Cesium Native 处理。
- DLL／Shader／字体缺失：检查安装与打包完整性，不能仅复制 ng-viewer.exe。
- CMake Cache 仍指向旧路径：为新配置选择新 build 目录，不批量替换 Cache 或递归清理。

本轮只做模块与 namespace 迁移；旧 out/install 和 out/desktop-native-sdk 保留，不能与 0.2 ABI 混用。原示例未接入 Demo。
