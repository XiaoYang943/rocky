# 安装、构建与使用

本文对应 GeoStudioNative 0.3.0／NativeSDK-004。当前支持本机 Windows x64 Release、MSVC 动态 CRT。本轮使用已有固定依赖 Cache 验证，不把新机器完整 bootstrap、Linux／macOS、Debug 或 GPU 画面记为已验证。

## 环境

- Visual Studio Installer：安装“使用 C++ 的桌面开发”、MSVC v143、Windows SDK；脚本用 vswhere 导入 x64 环境。本机沿用 MSVC 14.44.35207。
- PowerShell 7、Git、CMake 3.22+、Ninja 加入 PATH。本机沿用 CMake 4.3.2。
- Python 3.9+：来源 patch 导出、架构检查需要 Python；不需 pip 依赖。执行代码测试不需要显示器或 GPU。
- 固定 [GDAL SDK](../../../../packages/gdal/README.md)：工作区 `packages/gdal/sdk/gdal-3.12.2-windows-x64-msvc-sdk`，包含 headers、lib、bin、share 和 runtime-manifest.json。替代位置通过 NG_GDAL_SDK 指定，版本和构建配置必须一致。
- 运行三维软件另需支持 Vulkan 的 GPU 驱动。Vulkan Headers／Loader／glslang 由固定依赖提供，不要求完整 Vulkan SDK。
- SDK 不需要 Qt、Node 或 Rust；React／Tauri 宿主另需 Node／pnpm、Rust MSVC 工具链、WebView2，见 [Demo 指南](../../../../demo/native-gis-demo/docs/使用指南.md)。

## 首次准备

在 SDK 根执行；默认 Cache 为 SDK `.deps`。下载严格使用 dependencies.lock.json，不重新消费外部 Cache 中的 Rocky／vsgCs／vsgXchange 实现。

```powershell
Set-Location D:/code/xiaoyang943/Programming-Lab/GeoStudio/sdk/GeoStudio-Native
./scripts/bootstrap.ps1 -Jobs 6
./scripts/bootstrap-cesium.ps1 -Jobs 6
./scripts/verify-sources.ps1
./scripts/build.ps1 -Jobs 6 -WithTests
./scripts/verify-package.ps1
```

bootstrap 默认准备 SDK 基础依赖，不编译 ImGui。若还要构建当前 ImGui Demo，再执行 `./scripts/bootstrap.ps1 -Only imgui`，或首次准备时使用 `-WithHostUi`。Demo 自己的 bootstrap 入口会显式请求此选项。

`-Offline` 只适用于源码、工具和下载 Cache 已齐备的环境。基础库可用 `-From vsg` 续建，内存不足降低 Jobs。不要删除失败 Cache；脚本不执行递归清理。

## 复用本机已有 Cache

```powershell
$env:GEOSTUDIO_NATIVE_DEPS = (Resolve-Path ../../demo/native-gis-demo/.deps).Path
./scripts/build.ps1 -Jobs 6 -WithTests
./scripts/verify-package.ps1
```

依赖来源在本次 PowerShell 中显式设置；安装后的 build-manifest.json 保存 dependencyRoot。更换机器应显式设置实际路径。新安装目录为 `out/install-capabilities`，旧 `out/install`／`out/install-modules` 保留，不可混用。

## 测试入口

`build.ps1 -WithTests` 编译 SDK 和代码测试，执行默认离线 CTest，任何失败停止安装。默认用例不创建 Window、Device、Viewer 渲染循环，也不读取 D:/data。小型 fixture 在 tests/capabilities/fixtures。

仅重跑已有构建中的特定用例，可在已设置 DLL／GDAL 环境的 PowerShell 中使用：

```powershell
. ./scripts/common.ps1
Enable-RuntimeEnvironment
ctest --test-dir .build/capabilities-r1 --output-on-failure
ctest --test-dir .build/capabilities-r1 -R architecture-contracts --output-on-failure
```

原外网／Vertical Datum Grid 用例保留，默认排除；显式设置 CMake `GEOSTUDIO_ENVIRONMENT_TESTS=ON` 才注册 environment-contracts。隐藏 issue229-repro 保留原标记，没有削弱断言，也没有将未运行记为通过。详见 [测试矩阵](../../tests/README.md)。

## 输出与消费

| 位置 | 内容 |
| --- | --- |
| .build/capabilities-r1 | SDK 构建、测试与 CTest 日志 |
| out/install-capabilities/include/geostudio/native | 显式公开 header 及生成配置；不含 ImGui、Cesium 私有 headers |
| out/install-capabilities/lib | 七个能力 static library、Import／RuntimeTiles import library、spdlog 和 CMake package |
| out/install-capabilities/bin | geostudio-import.dll、geostudio-runtime-tiles.dll |
| out/install-capabilities/share/GeoStudioNative | resources、provenance、licenses、build-manifest.json |

```cmake
find_package(GeoStudioNative 0.3 CONFIG REQUIRED)
target_link_libraries(my_app PRIVATE GeoStudio::Native)
# 只使用内存数据和空间计算的消费者可以链接 GeoStudio::Data。
```

CMAKE_PREFIX_PATH 需包含 SDK 安装目录、固定基础依赖和 Cesium dependency prefix；NG_GDAL_SDK 提供匹配的 GDAL。安装包不是含所有第三方库的独立发行 SDK。具体参数见 scripts/verify-package.ps1；该脚本构建并运行两个无窗口 consumer，禁用 ImGui package，检查新类型注册、Core/Data 链接、GLM 隔离及已安装 header 身份。

公开 API 使用 C++17；RuntimeTiles DLL 隔离 C++20 和 Cesium 的 GLM_FORCE_XYZW_ONLY。工具链、CRT、GLM、spdlog/fmt 版本必须匹配。

## 编译和打开 Demo

本轮只编译，不执行这些启动或打包步骤。用户后续手动验证时按以下顺序操作：

```powershell
Set-Location ../../demo/native-gis-demo
./scripts/build.ps1 -Jobs 6 -CompileOnly
./scripts/run-native.ps1
```

`-CompileOnly` 不运行样本生成器，也不启动渲染程序。需要重新生成本地样本时，去掉该参数。SDK 和 Demo 仍分别构建，不自动联建。

直接入口为 `build/native-modules/bin/ng-viewer.exe`，建议用 run-native.ps1，以设置 DLL 和资源路径。React 桌面包仍按 Demo 指南执行 stage-native 和 build-desktop；本轮没有重打桌面包，已有 `out/desktop-native-modules` 仍代表旧制品，不能将其当作 0.3 验收对象。后续打包前关闭被覆盖的运行包。

## 常见失败

- 找不到 GeoStudioNative 0.3：先构建 SDK，确认消费 out/install-capabilities。
- 找不到 imgui：仅 Demo／宿主 adapter 需要，执行 bootstrap -Only imgui；不要把它重新加入 SDK package。
- 来源 hash／patch 不匹配：先审查授权差异，执行 refresh-provenance.py 导出完整 patch，再 verify-sources；不能只改 hash。
- 缺 DLL／Shader：检查脚本环境和安装／打包闭包，不能只复制 EXE。
- Slughorn、MBTiles 等可选能力：源码保留不等于默认启用，本轮维持原功能边界。

## NativeSDK-004 的目录迁移

ImGui adapter 已移到 Demo native/ui，SDK 不再接受 GEOSTUDIO_BUILD_EXAMPLES；安装 consumer 已移到 tests/package-consumer。构建／运行命令保持上文入口，不要求把 GUI 源码复制回 SDK。

新安装只携带当前来源证明，完整历史在仓库 provenance 保留。增量安装不会删除旧文件；新发行目录需通过 `tests/architecture/check_package_contents.py --installed <目录>`。安装 consumer 可用 `scripts/verify-package.ps1 -InstallDirectory <目录>` 指定新安装路径，建议同时指定新的 BuildDirectory，避免原 CMake Cache 消费其他 package。

Demo staging 接受 -Destination 指定新目录，旧默认目录的历史文件需要用户手动清理；本轮不自动删包或发布。详见 [发行目录与清理清单](发行目录与清理清单.md)。
