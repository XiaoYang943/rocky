## 源码复核的实际范围

各章的 V、X、O 编号指向明确源码文件及稳定符号；本轮证据目录为 [.docs-tmp/render-foundations-p0-r1](../../../../../.docs-tmp/render-foundations-p0-r1)。

| 证据 | 记录内容 | 不能据此声称的事项 |
| --- | --- | --- |
| `baseline.json` | 两个 Git 根的 HEAD、跟踪文件初始 Hash、既有技术文档原文与 Hash、受保护锁及配置 | 不能证明历史改动已经验收 |
| `source-identities.json` | 交付文档引用的本地源码/配置文件、直接核对的资源头文件、版本定位与 SHA-256，含原术语表保留的 G 证据；不含检查报告本身 | 不表示原 G 组重新分析，也不表示整个调用图都已分析 |
| `upstream-comparison.json` | 七个关键实现文件与固定 Commit 的 raw 来源逐个比较，统一 LF 后相同 | 不是全部缓存源码的纯净证明，也没有拉取或覆盖文件 |
| `knowledge-review.json` | 查询、实际阅读位置、资料状态与适用性 | 未治理内容不能冒充现行已验证结论 |
| `symbol-checks.json` | 37 项关键源码符号/文本一致性检查 | 只辅助人工阅读，不是 AST 或兼容性测试 |
| `verification.json` | 本轮文档检查、内容身份、修改边界和未执行项 | AI 自检不代替人工验收或 GPU 测试 |

七个远端复核文件为 VSG 的 `Viewer.cpp`、`RecordTraversal.cpp`、`DatabasePager.cpp`，以及 vsgXchange 的 `all.cpp`、`3DTiles.cpp`、`Builder.cpp`、`b3dm.cpp`。首次比较命令因 Node 模块模式失败，未发生下载写入；改为只读请求后完成比较，报告保留该事实。其余文件以本地实际 Hash 和来源锁定位，不扩大远端复核范围。

## 已有 Demo 构建配置观察

这些是读取既有 Cache 与脚本的结果，本轮没有执行 CMake、安装依赖或启动软件。

## 知识检索与适用性

本轮执行知识工具 `lookup --include-candidates`：`VulkanSceneGraph`、`vsgXchange` 均无命中；`DatabasePager` 两条命中来自 OSGB 原文资料，状态均为尚未治理。已阅读其附近段落，内容可作 OSG Paging 的背景线索，不能作为固定版本 VSG 的实现或参数依据。

因此本轮主要依据本地源码定义、调用点及官方文档。未修改知识库或创建正式条目，后续验收/源码变化后再评估是否提炼通用知识。返回[总览](README.md)或阅读[主任务](../任务/002-渲染基础库架构调研.md)。
